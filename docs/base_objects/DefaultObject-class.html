DefaultObject

DefaultObject class abstract

Objeto base para entidades de domínio com identificador e datas de controle.

Quando não informado, o id é gerado no aplicativo — não um inteiro atribuído pelo banco. A diferença importa quando os dados são compartilhados entre lojas: duas unidades gravando ao mesmo tempo não colidem, e uma operação reenviada após falha de rede é reconhecida como repetida em vez de virar registro duplicado.
